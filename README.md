# Superstore Sales Dashboard - Power BI

## Project Overview
This project analyzes Superstore sales performance from 2014-2017 using Power BI. The dashboard provides insights into sales, profit, regions, segments, and categories to support business decision-making.

## Business Problem
Identify top performing regions, segments, and products, understand why some states are making losses, and recommend strategies to increase profit margin.

## Tools Used
- Power BI Desktop (Data cleaning, DAX, Visualizations)
- Excel - Superstore dataset
- GitHub for documentation

## Dashboard Features
- KPIs: Total Sales $2.30M, Total Profit $286.4K, Profit Margin 12.47%, Total Orders 5,009
- Sales by Region, Category, Segment (Consumer = 50.56%)
- Profit Performance by State - shows loss states: Texas, Ohio, Pennsylvania in brackets e.g. ($25,729)
- Annual Sales Trend (2014-2017)

## Key Insights
- West region drives highest sales and profit
- Consumer segment accounts for 50.56% of sales
- Technology is top category but Furniture drags profit down
- Texas, Ohio, PA are profitable in sales but loss in profit due to high discounts

## Recommendations
1. Scale winning states: California, New York, Washington
2. Focus on high-margin Tech products: Phones, Copiers
3. Stop heavy discounts in loss states
4. Launch loyalty program for Consumer segment (50.56% revenue)
